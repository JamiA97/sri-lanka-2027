# Sri Lanka 2027 Family Proposal

Mobile-first interactive family review site based on Kuoni proposal 420220-4 (Maalu Maalu version).

- No prices are exposed in the site.
- Route, hotel details, flights, transfers and included safaris are based on the proposal.
- Hotel links point to official hotel websites.
- Current comments prototype uses browser localStorage; a shared persistence layer is the next planned enhancement.

Static site: `index.html`, `styles.css`, `app.js`.
